## Getting Started
To get started with the Employee-Supper-App, follow these steps:

1. **Clone the Repository**:
   bash


git clone https://github.com/yourusername/Employee-Supper-App.git
cd Employee-Supper-App
2. **Set Up the Environment**:
   Ensure you have the following installed:
    - JDK 11 or higher
    - Gradle or Maven (depending on your build tool preference)

3. **Build the Application**:
   If using Gradle:
   bash


./gradlew build
If using Maven:
bash


mvn clean install
4. **Run the Application**:
   bash


./gradlew bootRun
or
bash


mvn spring-boot:run
5. **Access the Application**:
   Open your web browser and navigate to  http://localhost:8080 to access the application.
